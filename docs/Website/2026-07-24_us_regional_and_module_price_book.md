# New-US regional and module pricing

Date: 2026-07-24

## Website change

The pricing page now reads plan and module USD prices from the generated FlowIQ price payload instead of maintaining a second hard-coded USD plan map.

New-US plan pricing is:

- Starter Lite: $39/month
- Starter: $79/month
- Growth Lite: $179/month
- Growth: $299/month
- Professional: $599/month
- Scale: $999/month
- Enterprise: from $1,499/month, contracted

The page now publishes the USD module price list as well as the standard ZAR list. US visitors receive the new-US USD price book; other visitors retain the standard ZAR book. Availability still follows the chosen plan.

## PayFast wording

The public page states that US pricing uses the USD price book and that PayFast converts the ZAR settlement amount at checkout. This avoids representing FlowIQ's current PayFast recurring integration as native USD merchant settlement.

## Drift controls

- `pricing-data.json` is generated by the main app's `tools/generate-public-pricing-data.mjs`.
- `regional_prices.USD` supplies plan amounts.
- `price_usd` supplies module amounts.
- The obsolete hand-maintained `MARKETING_USD_PLAN_PRICES` object was removed.
- Homepage structured data and the legacy pricing redirect now use the $39 new-US entry price.
- Main-app tests assert the generated regional fields, visible module pricing and settlement wording.

## Deployment boundary

The website source is updated but is not deployed from this workflow. The owner deploys the standalone marketing repository through GitHub; Netlify deployment is intentionally not used.
